# Chiritsumo

Chiritsumo（ちりつも）は、日々の家事やお手伝いを子どもたちにとって楽しく魅力的なミニゲームに変えるプログレッシブウェブアプリ（PWA）です。アプリの名前は、「塵も積もれば山となる」ということわざに由来しています。小さな努力の積み重ねを通じて、良い習慣を身につけることを促します。

ゴミの分別や掃除などのタスクを完了することで、ユーザーはスタンプを獲得し、レベルアップし、楽しい豆知識を学ぶことができます。これにより、お手伝いが達成感のある体験になります。

## 機能

-   **ゲーム化されたお手伝いシステム**: ゴミの分別や掃除など、スワイプ可能なカルーセルからカテゴリーを選択してタスクに挑戦します。
-   **学びのあるヒント**: 各ミニゲームでは、そのお手伝いに関連した楽しく学べる「豆知識」が表示されます。
-   **スタンプコレクション**: タスクを完了するごとに、ランダムでユニークなスタンプを獲得できます。
-   **レベルアップ機能**: スタンプを4つ集めると「お手伝いレベル」が上がり、画面いっぱいの紙吹雪アニメーションでお祝いされます。
-   **お手伝い手帳**: カレンダー形式のページで、これまでに集めたスタンプを視覚的に確認し、達成したお手伝いの記録を振り返ることができます。
-   **魅力的なアニメーション**: 紙吹雪やアニメーション付きのリザルト画面など、達成感を高める視覚的なフィードバックを楽しめます。
-   **プロフィールのカスタマイズ**: 自分の名前を設定し、かわいい動物のアバターを選んでアプリを始められます。

## 技術スタック

-   **フレームワーク**: Angular 15
-   **言語**: TypeScript
-   **アニメーション**: お祝いのエフェクトに `canvas-confetti` を使用
-   **PWA**: Angular Service Worker を有効化し、インストール可能なネイティブアプリのような体験を提供

## はじめに

このプロジェクトをローカルで実行するには、Node.js と Angular CLI がインストールされている必要があります。

1.  **リポジトリのクローン:**
    ```sh
    git clone https://github.com/your-username/chiritsumo.git
    cd chiritsumo
    ```

2.  **依存関係のインストール:**
    ```sh
    npm install
    ```

3.  **開発サーバーの起動:**
    ```sh
    ng serve
    ```
    `http://localhost:4200/` にアクセスしてください。ソースファイルを変更すると、アプリは自動的に再読み込みされます。
